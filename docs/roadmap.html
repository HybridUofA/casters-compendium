Project roadmap

The deckbuilder is the foundation.

Follow each release from the first packaged deckbuilder through today's manual-playable simulator, with tag dates and a summary of what changed along the way.

Release timeline

How the project is evolving.

Completed entries use their Git tag dates. Planned releases remain undated until their scope and implementation are ready.

  1. v0.1.0

    First packaged deckbuilder

    Released July 17, 2026

    The first downloadable desktop release brought the established card browser and deckbuilding workflow to Windows, Linux, and both Intel and Apple Silicon Macs.

    • Search and filter the local card catalog.
    • Build and order main decks and sideboards.
    • Import and export JSON and text deck formats.
    • Create Tabletop Simulator image sheets.
    View the v0.1.0 release →

  2. v0.1.1

    Linux build reliability

    Released July 17, 2026

    A focused maintenance release corrected the Linux packaging prerequisites needed by Fyne's Wayland support, making the automated desktop build more dependable.

    • Repaired the Linux release workflow.
    • Kept the existing deckbuilder behavior stable.
    View the v0.1.1 release →

  3. v0.1.2

    Search, appearance, and Linux packages

    Released July 17, 2026

    The deckbuilder gained more expressive search and personalization while expanding from a general Linux archive to native Debian, Ubuntu, and Arch packages.

    • Added data-driven rules-keyword filtering.
    • Added system, light, and dark appearance settings.
    • Added a hash-verified GitHub data bootstrap.
    • Corrected canonical card-printing matches.
    View the v0.1.2 release →

  4. v0.1.3

    Refinement and shared architecture

    Released July 18, 2026

    A refinement release improved everyday deck editing and reorganized the project around shared card and game packages in preparation for simulator development.

    • Added hover previews and drag-to-search removal.
    • Corrected deck-grid alignment and sizing.
    • Introduced the new application icon.
    • Established the shared repository and project website.
    View the v0.1.3 release →

  5. v0.1.4

    Batch editing and direct TTS export

    Released July 23, 2026

    This deckbuilder release makes custom organization faster, adopts Speedrobo's published text format, and turns local Tabletop Simulator installation into a one-click workflow.

    • Select card copies with Control-click or Command-click.
    • Move selected cards within or between zones as one ordered batch.
    • Install a complete local Tabletop Simulator saved object in one action.
    • Detect standard TTS data locations and remember custom locations.
    • Import and export the text format published by Speedrobo Games.
    • Complete the current Fyne UI-thread migration.

    Requested by Speedrobo Games: one-click Tabletop Simulator export and compatibility with its published text decklist format.

    View the v0.1.4 release →

  6. v0.1.5

    Portable multiplayer TTS export

    Released July 23, 2026

    This patch makes one-click TTS objects portable between players and moves released card data onto publisher-authorized project infrastructure.

    • Reference reusable HTTPS card sheets that every multiplayer participant can load.
    • Install only the saved-object JSON instead of copying deck-specific images.
    • Retain the v0.1.4 local-sheet installer as an automatic offline fallback.
    • Distribute complete card databases and artwork from immutable hosted catalog releases.
    • Verify database size, SHA-256, schema, and card records before installation.

    Publisher authorization: Speedrobo Games explicitly permitted Caster's Compendium to host the supporting card images and data.

    View the v0.1.5 release →

  7. v0.1.6

    Selectable application backgrounds

    Released July 24, 2026

    This visual-personalization release adds approved Caster Chronicles artwork without changing the familiar default deckbuilding workspace.

    • Choose None, Academy Rift, or Caster Duel from Settings.
    • Apply background changes immediately and preserve them between launches.
    • Show the selected artwork behind setup, menus, progress screens, and the deck editor.
    • Maintain interface legibility with a consistent readability layer.
    View the v0.1.6 release →

  8. v0.1.6-hotfix.1

    Background rendering correction

    Hotfix prerelease July 24, 2026

    This focused hotfix corrects the framework-specific rendering incompatibility discovered after v0.1.6 packaging.

    • Expose background layers through a concrete Fyne container.
    • Render the selected artwork, readability layer, and controls in order.
    • Redraw the main menu immediately after saving appearance settings.
    • Add regression coverage for the renderer-compatible container type.
    View the hotfix prerelease →

    TTS and release-process candidate

    Release candidate July 25, 2026

    First installation candidate for sharper Tabletop Simulator exports, hosted catalog v2, and the candidate-to-stable release checklist.

    View the v0.1.7-rc.1 candidate →

  10. v0.1.7-rc.2

    Packaging follow-up candidate

    Release candidate July 25, 2026

    Second candidate on the path to stable v0.1.7 after packaging and smoke-test feedback on rc.1.

    View the v0.1.7-rc.2 candidate →

  11. v0.1.7

    Sharper TTS exports and safer releases

    Released July 26, 2026

    This release improves card clarity in Tabletop Simulator and adds a visible candidate-to-stable quality boundary.

    • Show the running application version on the main menu.
    • Build hosted and offline TTS sheets from full-resolution artwork.
    • Use native TTS deck objects and immutable hosted catalog v2.
    • Validate release-version metadata and report test coverage in CI.
    • Require human smoke testing of packaged candidates before stable publication.
    View the v0.1.7 release →

  12. v0.1.8

    Personal deck library and official Duel Decks

    Released July 26, 2026

    The editor makes saved decks easier to revisit and provides an offline starting point for every launch-wave Duel Deck published by Speedrobo Games.

    • Create a default personal Decks folder under Documents.
    • Switch between saved JSON decks and compatible text decklists in the editor.
    • Remember the active selection and protect unsaved changes.
    • Bundle all eight official DD01–DD04 decklists as read-only templates.
    • Default first-time users to DD01 Ignus.
    • Accept main-only text decklists and streamline the fixed editor layout.
    View the v0.1.8 release →

  13. v0.1.8-hotfix.2

    Stable catalog artwork recovery

    Hotfix prerelease August 10, 2026

    This hotfix keeps card setup working when upstream artwork links disappear and publishes hosted catalog v3 with immutable artwork URLs.

    • Fall back to version-controlled card images when an upstream request fails.
    • Publish normalized databases with catalog-owned artwork URLs.
    • Repair existing v0.1.8 installs automatically without changing deck files.
    View the hotfix prerelease →

    Release candidate September 11, 2026

    • Scale hosted Tabletop Simulator sheets and refresh Duel Deck artwork.
    • Browse gameplay-identical printings and historical deck compatibility.
    • Introduce early hotseat simulator scaffolding with documented limits.
    View the v0.2.0-rc.1 candidate →

  15. v0.2.0-rc.2

    Release candidate September 11, 2026

    Replaces rc.1 after correcting the Arch Linux manpage checksum used by the packaging workflow. Application behavior matches rc.1.

    View the v0.2.0-rc.2 candidate →

  16. v0.2.0-rc.3

    Text decklist and copy-limit fixes

    Release candidate September 15, 2026

    Fixes caster-level identity in Speedrobo text import/export and gives each caster level its own four-copy allowance.

    • Import and export Lv2 / Lv3 caster suffixes correctly.
    • Reject impossible level requests instead of silently substituting cards.
    View the v0.2.0-rc.3 candidate →

  17. v0.2.0-rc.4

    Local simulator interaction candidate

    Release candidate October 3, 2026

    Makes planned Aether payments and manual card effects easier to operate while keeping unsupported rules explicit.

    • Select recovered Caster-zone Aether sources while planning casts.
    • Move controlled printed cards manually between supported zones.
    • Refresh hosted catalog v6 with publisher-approved EX02 printings in normal search.
    • Remove stale Tabletop Simulator saved objects after a successful deck rename export.
    View the v0.2.0-rc.4 candidate →

  18. v0.3.0

    First public networked simulator

    Released October 3, 2026

    Introduces authoritative-host online play and packaged simhost alongside the existing hotseat path. Superseded by v0.3.2 for clean versioning.

    • Host or join rooms over WebSocket with player-chosen decks.
    • Ship Linux amd64 host tarball, systemd unit, and Docker recipe.
    • Add Host Online Game and Join Online Game to the main menu.
    View the v0.3.0 release →

  19. v0.3.1

    Network implementation milestone

    Superseded tag October 3, 2026

    Intermediate tag on the path to v0.3.2; use v0.3.2 or later for the supported public networked release.

    View the v0.3.1 tag →

  20. v0.3.2

    Clean public networked simulator

    Released October 3, 2026

    Supersedes the mislabeled v0.3.0 / v0.3.1 tags and ships the authoritative-host online path with player-chosen decks and Discord release announcements.

    • Online lobby with decks submitted on create/join.
    • Packaged simhost for LAN or cloud playtests.
    • Inherits rc.4 local casting, manual moves, and catalog v6.
    View the v0.3.2 release →

  21. v1.0.0

    Manual-playable networked simulator

    Released October 4, 2026

    The first stable rules-assisted simulator skeleton: turn structure, battle, Orb corruption, Break, and online lobby play are enforced enough for real playtests while most printed effects stay manual.

    • Named rooms, search, optional passwords, and spectators (protocol v3).
    • Battle judgment, Double Corrupt, Break queues, and mandatory-attack completion.
    • Cockatrice-style drag/move, deck dig/browse, Orb peek/reveal, and Sage Advice dig-on-draw.
    View the v1.0.0 release →

  22. v1.1.0

    Simulator playability and priority QoL

    Released October 5, 2026

    Fixes Call and Level Up freezes in hotseat and online, restores a usable Level Up prompt, and reduces empty priority click fatigue.

    • Host replies to the acting player before fanning views to peers.
    • Level Up selection in the preview action panel; Call row stays under the Hand.
    • Press Space to pass priority; auto-pass empty stacks until a Chase starts.
    View the v1.1.0 release →

  23. v1.1.1

    Manual Aether and click-to-attack Hubris

    Released October 8, 2026

    Adds Cockatrice-style Aether pool editing, finishes Orb-zone player-attack clicks with printed Hubris support, and ships the official non-elemental Aether symbol.

    • Left-click / right-click your Aether pool to add or remove one of each type (zeros stay visible).
    • After selecting an attacker, click an enemy Servant or Orb zone to declare the attack.
    • Printed Hubris bypasses Reversed-Servant player-attack blocks.
    View the v1.1.1 release →
