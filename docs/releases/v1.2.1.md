# Caster's Compendium v1.2.1

v1.2.1 is a playability polish release on top of v1.2.0: clearer card actions,
stronger Barrier vs Servant rules, orb costs for effect cards, and an obvious
end-of-match flow with lobby cleanup.

## Board UX

- Call, Cast, Level Up, and Move move off the left-rail Actions strip onto card
  right-click menus (Cast and Move open dialogs).
- The side panel splits **Events** and **Chat** into separate tabs.
- Right-click an Orb to Corrupt or Banish for effect resolution (Peek / Reveal
  remain available where they already applied).
- Dragging a card shows a translucent ghost under the pointer.
- Targeting highlights the card under the cursor (Corrupt / Peek / Reveal, and
  attack targets).
- Orbs use fixed prize-style slots with empty outlines when removed, so the
  remaining Orbs do not slide together.
- Aether pool icons wrap in the sidebar instead of using a horizontal scrollbar.

## Rules and effects

- Barriers are no longer treated as servants for attack targets, reversed
  blockers, servant counts (for example Charyl Thomas), or servant-targeting
  effects such as Abolition.
- Barriers may only be Recovered or Rested (not Reversed).
- Vega Scarlet Star Rest offers banish an allied orb, then corrupt a target.
- Straw Effigy Enter offers corrupt an allied orb instead of auto-moving orb 0.

## Match end and lobbies

- Victory / Defeat / Draw dialog when a match finishes (reason included).
- Confirming OK returns to the menu; hotseat closes the Player Two window.
- Finished online rooms are removed from the open lobby after the finished view
  is pushed.

## Compatibility

Deck files, settings, and protocol version 3 are unchanged. Online play should
use a `simhost` built from this tag (or later) so manual orb corrupt/banish and
finished-room cleanup match the client.
