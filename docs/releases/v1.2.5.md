# Caster's Compendium v1.2.5

v1.2.5 is the intended desktop reliability patch: the app prompts when a newer
release is available, and Windows maximize / resize no longer drives the window
under the taskbar or desyncs the mouse from on-screen buttons.

**Note:** The GitHub tag `v1.2.4` was created on the v1.2.3 source by mistake, so
packages labeled 1.2.4 were still 1.2.3. Install **v1.2.5** for these fixes.

## Update discovery

- On launch, the application quietly compares itself to the latest stable GitHub
  release.
- When a newer version exists, a dialog offers **Open Downloads** (the public
  downloads page), **Later**, or **Skip This Version**.
- **Check for Updates** on the main menu runs the same check on demand and
  reports when you are already current.
- Offline or failed checks stay silent for automatic startup prompts; manual
  checks show a clear failure message.

## Windows window geometry

- Softened layout minimum sizes so the window can resize vertically again and
  Fyne stops forcing a height taller than the visible desktop.
- Deck grids no longer claim full-deck height as the window minimum (tiles still
  shrink to fit).
- On Windows, the window is clamped to the monitor work area (above the taskbar)
  after content loads, recovering from maximize-under-taskbar cases that caused
  pointer hit-testing to drift downward.
- Fyne is updated to v2.8.2 for related desktop window fixes.

## Compatibility

Deck files, settings, card catalog, simulator protocol, and online play behavior
are unchanged. This is a client-only desktop shell update.

## AI transparency

Hybrid directed the update-discovery and Windows maximize / mouse-desync work,
and remains responsible for acceptance and publication. Cursor assistance
implemented the update check, work-area clamping, layout minimum fixes, tests,
transparency updates, and release metadata under maintainer review. See
[AI_STATEMENT.md](../../AI_STATEMENT.md).

## Release verification

This release includes SHA-256 checksums, an SPDX software bill of materials, and
GitHub artifact attestations. Windows and macOS packages remain unsigned and
may display a first-launch security prompt.
