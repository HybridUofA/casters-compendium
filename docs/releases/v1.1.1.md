# Caster's Compendium v1.1.1

v1.1.1 is a small playability release on top of v1.1.0. It adds manual Aether
pool editing for effect resolution, finishes click-to-attack against the enemy
player via the Orb zone, recognizes printed Hubris for that path, and ships the
official Speedrobo non-elemental Aether symbol.

## Manual Aether adjust

- Left-click an Aether type in your pool to add one; right-click to remove one
  (cannot go below zero).
- Your editable pool always shows all nine types, including zeros, so you can
  create a type from empty.
- Opponent pools remain view-only.
- Available in hotseat and online (`adjust_aether`); no priority or phase gate,
  matching other Cockatrice-style manual aids.

## Battle click targeting and Hubris

- After selecting a Recovered Servant, left-click an enemy Servant to attack it,
  or left-click the enemy Orb zone to attack the player.
- Printed Hubris on the attacker allows a player attack even while a Reversed
  enemy Servant is in play.
- Granted / until-EOT Hubris is not modeled yet.
- Right-click Orb peek/reveal is unchanged.

## Presentation

- Replace the AI-generated non-elemental Aether placeholder with official
  Speedrobo artwork (also disclosed in AI transparency).

## Compatibility

Deck files, settings, and protocol version 3 are unchanged. Online play should
use a `simhost` built from this tag (or later) so `adjust_aether` is available
on the host.
