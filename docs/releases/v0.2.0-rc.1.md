# Caster's Compendium v0.2.0-rc.1

v0.2.0-rc.1 is an installation candidate for the expanded card catalog,
alternate-art browsing, historical deck compatibility, and the latest
simulator groundwork. It is a prerelease pending hands-on platform and visual
acceptance.

## Card catalog and artwork

- Refresh the bundled and hosted catalog from 226 to 379 current publisher
  records.
- Add the latest Duel Deck and expansion definitions and artwork.
- Normalize source-only rarity, alternate-art, sample, and caster-level labels
  without changing printed gameplay names.
- Scale the hosted Tabletop Simulator catalog to six sheets with up to 70 cards
  per sheet.

## Alternate artwork

- Show one search result for gameplay-identical cards by default.
- Choose the exact artwork and printing from the card-information panel.
- Optionally show each distinct artwork as its own search result.
- Preserve the chosen printing through right-click, drag-and-drop, saved decks,
  and exports.

## Historical deck compatibility

- Resolve the ten publisher IDs replaced during the catalog refresh, including
  Carella Level 2 ID `235` as canonical ID `1225`.
- Migrate aggregate deck entries and per-copy order when an older deck opens.
- Merge entries that resolve to the same canonical printing.
- Carry legacy IDs and alias chains forward during later catalog refreshes.
- Resolve historical IDs against canonical hosted Tabletop Simulator slots
  without adding duplicate search cards or sheets.

## Simulator groundwork

- Add an explicit per-element aether-payment model and payment validation tests.
- Continue the in-progress call and level-up engine groundwork. The simulator
  remains experimental and is not presented as a complete game mode.

## Candidate testing status

Automated default and migrated-Fyne test suites, formatting checks, version
consistency, and a production-shaped catalog build are part of candidate
validation. Manual visual, installation, platform, and Tabletop Simulator smoke
tests remain required before stable `v0.2.0` approval.

## AI transparency

Hybrid selected this scope and explicitly authorized OpenAI Codex to implement
the UI, compatibility infrastructure, automated tests, release preparation,
catalog publication, and release-candidate packaging. Hybrid retains
responsibility for hands-on acceptance and stable-release approval. See
[AI_STATEMENT.md](../../AI_STATEMENT.md) for the complete disclosure.

## Release verification

The release workflow publishes SHA-256 checksums, an SPDX software bill of
materials, and GitHub artifact attestations. Windows and macOS packages remain
unsigned and may display a first-launch security prompt.
