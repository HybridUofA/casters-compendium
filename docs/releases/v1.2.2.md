# Caster's Compendium v1.2.2

v1.2.2 is a small playability patch on top of v1.2.1: Break decisions no longer
leak privately known information, and forced-discard / pending-choice prompts
are readable enough to use in real matches.

## Break privacy

- After Orb corruption, the owner always gets a prompt — Use/Decline Break when
  legal, otherwise Continue.
- Opponents still only see that a decision is outstanding, so a missing wait no
  longer reveals whether the corrupted card prints Break.

## Pending choice UX

- Discard and other card-targeting prompts show printed card names instead of
  Match IDs such as `player-1-card-26`.
- Click a highlighted hand or field card to select it (single-card discards such
  as Ouroboros submit immediately; two-card discards accept two clicks).

## Compatibility

Deck files, settings, and protocol version 3 are unchanged. Online play should
use a `simhost` built from this tag (or later) so Break acknowledge timing and
pending-choice resolution match the client.

shipping as a patch release, and remains responsible for acceptance and
publication. Cursor assistance implemented the engine/UI wiring, tests,

## Release verification

This release includes SHA-256 checksums, an SPDX software bill of materials, and
GitHub artifact attestations. Windows and macOS packages remain unsigned and
may display a first-launch security prompt.
