# Caster's Compendium v0.2.0-rc.4

v0.2.0-rc.4 is a local simulator interaction candidate. It makes planned
Aether payments and manual card effects easier to operate while keeping the
prototype's unsupported rules explicit.

## Planned casting

- Select recovered face-up, face-down, or token Caster-zone sources while
  preparing a Servant, Conjure, or Barrier cast.
- Validate the prospective Aether pool before changing match state.
- Apply source generation, payment, card play, Chase creation, priority
  transfer, and the revision increment as one command.
- Reject duplicate, stale, or illegal plans without partially changing the
  match.

## Manual card movement

- Move a controlled printed card between supported Hand, Deck, Graveyard,
  Exile, Caster, and Servant zones.
- Choose top or bottom placement when returning a card to its owner's Deck.
- Transfer a field card between players while preserving its face and
  orientation.
- Keep each player's projection private after a move.

Tokens, cards with Stock, Orb insertion, hidden Deck or Orb selection, and
face-down Exile remain intentionally unsupported in this prototype.

## Card catalog v6

- Refresh the 379-card publisher snapshot without changing stable card IDs.
- Move 80 EX02 and related printings from playtesting-only visibility into the
  normal searchable catalog, matching the current publisher data.
- Publish the reviewed database and existing approved artwork as immutable
  hosted catalog v6.
- Allow a failed pre-pointer publication to resume only when the existing
  immutable manifests match, and retry cache-busted public-origin checks.

## Tabletop Simulator renamed decks

- Remove the obsolete app-owned saved object only after a renamed deck exports
  successfully, so Tabletop Simulator no longer continues to offer the
  previous deck name.
- Preserve the current export when old and new names sanitize to the same
  cross-platform filename.
- Update the editor window title immediately after a deck rename.

## Presentation and testing

- Refine the two-player battlefield, reversed-card rendering, selection borders,
  suggested-cast controls, and manual-move panel.
- Add regression coverage for planned Servant, Conjure, and Barrier casts,
  rejected command atomicity, stale revisions, private projections, manual-move
  choices, and minimum board sizing.
- Add simulator-specific candidate checks to the human release checklist.

The release workflow publishes SHA-256 checksums, an SPDX software bill of
materials, and GitHub artifact attestations. Windows and macOS packages remain
unsigned and may display a first-launch security prompt.
