# Caster's Compendium v0.2.0-rc.3

v0.2.0-rc.3 is a deck-editor compatibility candidate that fixes the two
card-level identity bugs reported after rc.2. It retains the expanded catalog,
alternate-art browsing, historical deck compatibility, and simulator groundwork
from the earlier v0.2.0 candidates.

## Speedrobo text decklists

- Import higher-level caster names such as `Arthur Lv2` against the normalized
  shared catalog.
- Export higher-level casters with the `Lv2`, `Lv3`, and later suffixes expected
  by Speedrobo's text importer.
- Keep Level 1 and higher-level caster lines distinct during a text round trip.
- Reject a requested higher-level caster when only a different level exists
  instead of silently substituting it.

## Deck copy limits

- Give each caster level its own four-copy allowance.
- Continue counting alternate artwork and reprints of the same caster level
  together, so choosing another printing cannot bypass the limit.
- Apply the corrected identity consistently across the main deck and side deck.

## Candidate testing status

The reported `Arthur Lv2 (DD02: Away Game)` import is covered against the
bundled production catalog. Automated default and migrated-Fyne suites, vet,
formatting, version consistency, and multi-platform packaging remain release
gates. Manual editor and Speedrobo website smoke tests remain required before
stable `v0.2.0` approval.
