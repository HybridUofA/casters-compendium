# Caster's Compendium v0.1.7-rc.1

This release candidate improves Tabletop Simulator image clarity and introduces
the project's candidate-to-stable release safeguards. It is intended for
package, visual, and export acceptance testing before the stable v0.1.7 tag.

## Sharper Tabletop Simulator exports

- Generate hosted TTS sheets from the full-resolution card-art cache.
- Limit hosted sheets to three cards in one row so TTS receives substantially
  clearer card faces.
- Scale offline fallback sheets from their cached source artwork while keeping
  the complete texture within an 8192-pixel compatibility boundary.
- Export native `DeckCustom` objects so saved decks receive the expected TTS
  deck behavior and icon.
- Publish immutable hosted catalog v2 and retain catalog v1 for existing saved
  objects.

Existing saved TTS objects continue to reference their original sheets. Export
the deck again after updating to use catalog v2.

## Release-process safeguards

- Establish `VERSION` as the authoritative public version.
- Validate application, package, documentation, and tag metadata in CI.
- Record package-level coverage for default and migrated-Fyne test modes.
- Add a reusable human smoke-test checklist and candidate-to-stable process.
- Add updater and next-release planning documentation.

## Candidate testing

Please test the actual package for your operating system, paying particular
attention to startup, selectable backgrounds, deck editing, database updates,
and a newly exported deck inside Tabletop Simulator. Report failures before the
stable v0.1.7 release.
