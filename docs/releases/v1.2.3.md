# Caster's Compendium v1.2.3

v1.2.3 is a playability patch: Instant-speed Rest for casters and servants,
level-up Stock banish costs that humans can actually pay, Battle no longer
soft-locks after bouncing an attacker, Save As names feed TTS Install, and
anonymous Orb backs render against older hosts. Release tags also redeploy
`simhost` when repository secrets are configured.

## Instant activated Rest (CR 1.2)

- Printed Rest abilities on Casters and Servants can be activated whenever you
  hold priority in any phase (not Main-only).
- Casters prompt Aether vs Rest when both are legal; Servants expose Rest on
  the right-click menu.
- Hilde Willow keeps her private enemy-deck peek; other Rest automation uses
  `activate_registered_rest`.

## Stock banish

- Level-up Stock is projected with card names so pending “banish from Stock”
  prompts are usable.
- Online clients need a matching `simhost` for the new Rest command.

## Battle attack clear

- Bouncing, destroying, or reversing an attacking Servant clears `Attack` so
  Battle can end (fixes the Straw Effigy / “attack in progress” hang).

## Deck Save As / TTS

- Save As sets the deck name from the chosen JSON filename so Install to TTS
  no longer requires a separate Rename.

## Orb backs and simhost deploy

- Anonymous face-down Orbs (empty MatchID from older hosts) show card backs
  instead of empty prize outlines.
- GitHub Actions can redeploy `simhost` on `v*` tags when `SIMHOST_HOST` and
  `SIMHOST_SSH_KEY` secrets are set.

## Compatibility

Deck files, settings, and protocol version 3 are unchanged. Online play should
use a `simhost` built from this tag (or later) so Instant Rest and Stock prompts
match the client.
