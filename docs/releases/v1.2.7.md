# Caster's Compendium v1.2.7

v1.2.7 ships the redesigned main menu and bundled title graphic contributed by
DukeDesmond, plus small Windows window-geometry and test updates that landed
with that work.

## Main menu and branding

- New main-menu layout with a slide-out sidebar for secondary actions.
- Bundled title logo (`data/logo/title.png`) shown on the home screen.
- In-app changelog access remains available from the menu.

## Compatibility

Deck files, settings, card catalog, simulator protocol, and online play behavior
are unchanged. This is a desktop presentation update.
