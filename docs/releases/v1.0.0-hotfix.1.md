# Caster's Compendium v1.0.0-hotfix.1

This prerelease hotfix stops Call / Level Up from freezing the simulator in
hotseat and online matches.

## Simulator freeze repair

- Defer hotseat board refreshes with `fyne.Do` so Level Up / Call buttons are
  not destroyed mid-tap.
- Defer automatic priority pass until after the current view apply finishes,
  avoiding interleaved rebuilds during Call.
- On the authoritative host, reply to the acting player before fanning views to
  peers; peer writes use a short timeout and a per-connection write mutex so a
  stalled opponent cannot block the actor's command round-trip.
- Join-room view fan-out is also asynchronous for the same reason.
- Add a regression test that a mutating command returns while a peer write is
  blocked.

Online play also needs a redeployed `simhost` built from this tag (or later)
so the host-side reply-first path is live.

## Compatibility

Deck files, settings, and protocol version 3 are unchanged. Existing v1.0.0
clients still need this client build for the UI-thread deferrals; the host
fix requires the updated simhost binary.
