# Caster's Compendium v0.3.2

v0.3.2 is the clean public networked simulator release. It supersedes the
mislabeled v0.3.0 / v0.3.1 tags and ships the authoritative-host online path
with player-chosen decks.

## Online multiplayer

- Host or join a room against an authoritative simulator host (`simhost`).
- Choose your own saved or official template deck before connecting.
- Exchange hello, create/join, match commands, and private views over protocol
  version 2 JSON WebSocket messages.
- Keep hotseat play on the desktop as a separate local path.

## Simulator host packaging

- Ship `cmd/simhost` with a Linux amd64 release tarball, systemd unit, and
  Docker image recipe for LAN or cloud playtests.
- Start each filled room from the two decks submitted on create/join.
- Announce GitHub releases to Discord automatically after packaging publishes
  the release assets.

## Presentation

- Add Host Online Game and Join Online Game actions to the main menu.
- Default the connect dialog to the deployed public playtest host when present.

## Inherited from v0.2.0-rc.4

- Planned Aether-source casting and manual card movement in the local
  simulator prototype.
- Hosted catalog v6 and the renamed Tabletop Simulator deck export cleanup.
