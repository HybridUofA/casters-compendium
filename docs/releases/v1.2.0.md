# Caster's Compendium v1.2.0

v1.2.0 is a playability release that turns the simulator from mostly-manual
effects into catalog-backed Enter / Rest / Resolve automation, adds Solo vs
Tsubasa, and fixes local-play gaps that left Break Enter (and related hooks)
silent.

## Effect automation

- Registers the shipped `master_effects` table for local hotseat and Solo as
  well as networked `matchboot` matches (local games previously never called
  `RegisterDefaultEffectHandlers`).
- Automates a large set of Enter, Rest, Resolve, Attack, and End-of-turn
  recipes through `internal/simulator/effects` and leaf `engine/ops` mutators.
- PendingChoice targeting continues for destroy / buff / search-style prompts;
  chase pauses while a required target is open (for example Firewheel Enter).

## Solo vs Tsubasa

- Main-menu **Solo vs Tsubasa** seats you as Player One against a local Passion
  Wing persona on Player Two (official DD01 Ignus list).
- Tsubasa calls face-up casters, produces aether, casts when able, prefers
  Passion Wing Rest before swinging, and answers Break / PendingChoice
  aggressively.
- Same `Agent` / driver interface is ready for later captains (Saaya, TENGU,
  Dream 7, other elements).

## Battle and board UX

- Click enemy Orb cards to corrupt after a player attack (no checkbox popup);
  Peek / Reveal use click-to-pick after the context menu.
- Barriers no longer count as mandatory attackers or selectable attackers.
- Empty Battle priority stays with the turn player while recovered Servants can
  still attack (avoids the Priority `-` soft-lock).
- Arena-style empty Battle can auto-skip when no legal attack or usable
  activated ability remains (abilities that need missing targets do not stop).

## Compatibility

Deck files, settings, and protocol version 3 are unchanged. Online play should
use a `simhost` built from this tag (or later) so effect registration and
pending-choice / Break resolution match the client.

## AI transparency

Hybrid directed the v1.2.0 automation, Solo AI, Battle/Barrier UX fixes, and
shipping as a minor release, and remains responsible for acceptance and
publication. Cursor assistance implemented ops/effects wiring, Tsubasa policy
and lobby hook, board UX, tests, transparency updates, and release metadata
under maintainer review. See [AI_STATEMENT.md](../../AI_STATEMENT.md).

## Release verification

This release includes SHA-256 checksums, an SPDX software bill of materials, and
GitHub artifact attestations. Windows and macOS packages remain unsigned and
may display a first-launch security prompt.
